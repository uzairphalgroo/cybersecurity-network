## 🚨 Reporting a Vulnerability

We take the security of AuditHound very seriously. If you believe you have discovered a vulnerability or security flaw in AuditHound itself:

1. **Do not** open a public GitHub issue.
2. Please report the issue privately by emailing `security@audithound.io` (or opening a private GitHub Security Advisory).
3. Include detailed steps to reproduce, the impacted component, and potential mitigation strategies.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
