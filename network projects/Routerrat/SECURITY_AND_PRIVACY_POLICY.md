# SECURITY AND PRIVACY POLICY

## Privacy Policy
RouterRat is designed as a stateless, local-first visualization dashboard.

1. **No Data Collection:** We do not collect, store, or sell any personal identifying information (PII) of our users.
2. **Telemetry Data:** The application consumes public BGP routing data (e.g., from RIPE RIS Live) to visualize the internet topology. This telemetry data is transient and exists solely in memory during your active session.
3. **Third-Party Services:** The platform may pull GeoJSON maps or data from public APIs. Refer to their respective privacy policies.

## Security Policy
RouterRat takes security vulnerabilities seriously.

### Reporting a Vulnerability
If you discover a security vulnerability within RouterRat, please open an Issue on our GitHub repository with the tag `security`. 
Do not exploit the vulnerability.

### Liability Declaration
RouterRat is an open-source tool provided without warranty. Users are responsible for securing their own deployment environments. The maintainers are strictly absolved of any legal or financial liability arising from breaches or unauthorized access to systems where this software is deployed.
